# Synergy Corp - Screeps Automation

A Screeps automation project themed around a mid-sized corporation that, against all odds, runs a functioning empire. Focused on modular systems, stable logistics, and iterative strategy. Nobody is sure what the company makes. Quarterly growth is up anyway.

## Features

- A staff of corporate role units: intern, admin, facilities, helpdesk, offshore, and shipping
- Tick-driven orchestration for memory, spawning, structures, towers, and pixels
- Room planning with roads, containers, ramparts, towers, and expansion support
- Practical automation priorities for economy stability, fortification, and controller progress
- Designed for clarity, modularity, and ease of iteration

## Tech Stack

- Language: TypeScript
- Package Manager: Yarn
- Editor: Visual Studio Code
- Environment: Screeps MMO sandbox
