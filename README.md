# Kingdom of Lorencia - Screeps Automation

A Screeps automation project themed around a small medieval kingdom where every room is a castle and wandering merchants come to the gates to trade. Focused on modular systems, stable logistics, and iterative strategy. Nobody is sure where all the Jewels of Bless come from. The controller keeps leveling anyway.

## Features

- A court of castle role units: villager, barmaid, mason, blacksmith, nomad, and caravan
- Tick-driven orchestration for memory, spawning, structures, towers, and pixels
- Room planning with roads, containers, ramparts, towers, and expansion support
- Practical automation priorities for economy stability, fortification, and controller progress
- Designed for clarity, modularity, and ease of iteration

## Tech Stack

- Language: TypeScript
- Package Manager: Yarn
- Editor: Visual Studio Code
- Environment: Screeps MMO sandbox
